# ~/claude-projects/marketplace/README.md

Plugins marketplace

A plugin marketplace is just a marketplace.json file listing plugins and where to fetch them — git repos, npm packages, or local paths. Add one, install what you want, get updates when the source changes. The vibe-coding-toolkit repo is one such marketplace.

# add this marketplace

/plugin marketplace add Searchadx360/Vibe-Coding-Project-Structure-and-Toolkit

# why bundle instead of copy-paste

Anything in the toolkit's agents/, skills/, commands/, or hooks/ folders can be copied straight into a project's .claude/ directory — no marketplace needed. Installing as a plugin instead buys you three things: one command to add it to a new project, automatic updates when the bundle changes upstream, and namespacing (review-suite:code-reviewer) so two plugins can ship an agent with the same name without colliding.
