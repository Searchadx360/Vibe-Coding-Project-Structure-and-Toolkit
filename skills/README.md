# Skills

Copy-paste-friendly `SKILL.md` files. Drop a folder into your project's
`.claude/skills/` (project-only) or `~/.claude/skills/` (all your projects).

| Skill | What it does |
| --- | --- |
| [`vibe-coding-project-structure`](vibe-coding-project-structure/SKILL.md) | **Flagship.** Scaffolds a whole project for AI-assisted development — CLAUDE.md, `.claude/` (rules/commands/skills/agents/hooks), a deterministic skill-triggering hook, MCP config, and optional GitHub Actions. Has its own bootstrap script; see [`vibe-coding-project-structure/README.md`](vibe-coding-project-structure/README.md) |
| [`testing-patterns`](testing-patterns/SKILL.md) | House testing conventions Claude applies automatically |
| [`schema-review`](schema-review/SKILL.md) | Reviews schema/API changes for compatibility and validation gaps |
| [`commit-message-writer`](commit-message-writer/SKILL.md) | Writes a Conventional Commits message from staged changes (`/commit-message-writer`) |

See [`code.claude.com/docs/en/skills`](https://code.claude.com/docs/en/skills)
for the full frontmatter reference.
